# Legacy versions

Kept for reference. These pages describe the original plugin as it was used with Capacitor 2–6. New integrations should use `@dwbn/capacitor-video-player` 8.x.

| Line | npm package | Capacitor | Maintainer |
|---|---|---|---|
| 1.x–5.x | `capacitor-video-player` | 1–5 | Jean Pierre Quéau |
| 6.x | `capacitor-video-player` | 6 | Harmon Wood |
| 7.x–8.0 | `@brylsherbert/capacitor-video-player` | 7–8 | brylsherbert247 |
| 8.x | `@dwbn/capacitor-video-player` | 8 | phiamo / DWBN (current) |

- [Notes on ExoPlayer 2.18.1](./Notes_Exoplayer2.18.1.md): the Android stack before Media3 (8.3.0)
